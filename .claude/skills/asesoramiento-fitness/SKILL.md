# Asesoramiento de Redes Sociales — Nicho Fitness

Este es el proceso de consultoría que sigue el usuario con sus clientes. Úsalo como contexto para dar respuestas alineadas con su metodología.

## Fases del Proceso

### 1. Bienvenida y Acceso a la Plataforma
- Se le da acceso al cliente a una plataforma de formación
- Lo primero que ve es un **video de bienvenida**

### 2. Estrategia Predefinida
- Se le envía al cliente la **estrategia predefinida**

### 3. Formaciones
El cliente completa dos módulos de formación:
- **Mentalidad** — base mental para crear contenido de forma consistente
- **Bases técnicas de creación de contenido** — fundamentos prácticos

### 4. Avatar y Propuesta de Valor
- Se trabaja con el cliente para **aterrizar su avatar** (cliente ideal)
- Se define su **propuesta de valor** diferencial

### 5. Acompañamiento 1:1 (fase continua)
Grupo de trabajo individual con el cliente:

1. **Ideas** — el cliente aporta ideas de contenido
2. **Selección** — se eligen las ideas con más potencial
3. **Guion** — el cliente diseña el guion del contenido seleccionado
4. **Revisión del guion** — el usuario revisa y corrige el guion
5. **Grabación y edición** — el cliente graba y edita el contenido
6. **Revisión final** — revisión de la grabación y edición por si hay que modificar algo

## Cómo Ayudar

Cuando el usuario trabaje en este contexto:
- Si revisa un **guion**: evaluar claridad, gancho inicial, estructura narrativa y llamada a la acción
- Si trabaja el **avatar**: ayudar a definir demografía, problemas, deseos y lenguaje del cliente ideal
- Si trabaja la **propuesta de valor**: ayudar a articular qué hace único al cliente frente a otros creadores de fitness
- Si selecciona **ideas**: evaluar potencial de engagement, originalidad y alineación con el avatar
- Si revisa **grabación o edición**: dar feedback sobre presentación, ritmo, claridad y retención
